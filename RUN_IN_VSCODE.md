# Run this portfolio in VS Code

1. Open this folder in VS Code.
2. Open the terminal (Terminal > New Terminal) and run:
   npm install
   npm run dev
3. Open http://localhost:8080 in your browser.

The site is already connected to its online database, so demo content appears right away.

## Admin area
- Go to /admin/login and sign up with your email.
- Then tell the Lovable assistant the email you used so it can grant you admin rights.

## Editing content
Once you are an admin, open /admin to edit your profile, resume, projects,
achievements, messages, and site settings. All changes appear on the public
site immediately.
